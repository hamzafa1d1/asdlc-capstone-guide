# ASDLC Capstone Guide

A step-by-step guide for the **Agentic AI & ASDLC** capstone projects supervised by Hamza Faidi at SUP'COM (2026–27).

**Live site:** https://hamzafa1d1.github.io/asdlc-capstone-guide/

It covers:
- **Shared path:** the free AI toolkit, core concepts (LLM, agent, harness, MCP, Skills, RAG, evals) with sources to read and watch, and the building blocks every team produces.
- **Three project tracks**, each with milestones, what to build, what to deliver, and checks that measure progress:
  - Hamza 1: AI Pull Request Reviewer with a Team Playbook
  - Hamza 2: Production-Grade Documentation Q&A Agent
  - Hamza 3: Multi-Agent Feature Development Pipeline (Spec → PR)
- **Final delivery:** the grading rubric and the submission checklist.

The official scope is the [ASDLC Capstone Projects document](https://docs.google.com/document/d/1vXNRej6hJEaWrtFM7qIWMgIDCAGHGPS0MogUjb9GLoE/edit?usp=sharing). If this guide and that document disagree, the document wins.

## Editing
All content lives in `data.js`, and `app.js` only renders it. It's plain static HTML/CSS/JS with no build step: edit a file, commit, and GitHub Pages redeploys.

Progress checkmarks are saved in each student's browser only (localStorage).
